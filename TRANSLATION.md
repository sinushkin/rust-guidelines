# Инструкция по переводу книги на русский

Перевод делается **не полным**: оригинал остаётся, а под каждым абзацем (пунктом списка, строкой цитаты) добавляется русский аналог.
Эталон оформления — `src/guidelines/README.md` (страница About).

## Формат

1. Оригинальный английский текст **не изменять и не удалять**.
2. Под каждым абзацем текста добавить пустую строку и русский перевод в виде:

   ```markdown
   English paragraph.

   <span class="ru">Русский перевод абзаца.</span>
   ```

3. Внутри `<span class="ru">` работает обычный inline-markdown (`**жирный**`, `` `код` ``, ссылки, `_курсив_`). Перевод — одна строка, без переносов внутри `<span>`.
4. Пункты списков: перевод — вложенным пунктом с отступом в 2 пробела под оригиналом:

   ```markdown
   - English item.
     - <span class="ru">Русский пункт.</span>
   ```

5. Цитаты (`>`): перевод — отдельным абзацем внутри той же цитаты:

   ```markdown
   > English note.
   >
   > <span class="ru">Русская заметка.</span>
   ```

## Что переводить

- Заголовки: переводить **заголовок отдельной строкой `<span class="ru">` под заголовком**. Заголовок `## ... { #M-FOO-BAR }` не трогать (якорь `{ #M-... }` должен остаться), перевод заголовка — обычным абзацем сразу под ним.
- Теги `<why>...</why>`: перевод — новой строкой под тегом, внутри `<span class="ru">` (без тегов `<why>`).
- Обычный текст, пункты списков, цитаты — переводить.

## Таблицы и чек-лист

- Таблица: оригинал не менять, под ней добавить копию таблицы с переведёнными ячейками (каждая текстовая ячейка в `<span class="ru">`, код и идентификаторы без изменений).
- Чек-лист (`src/guidelines/checklist/README.md`): под пунктом `- [ ] ... ([M-FOO])` добавлять вложенный пункт с переводом названия: `  - <span class="ru">...</span>`. Определения ссылок внизу файла не трогать.

## Что НЕ переводить и не менять

- Блоки кода (``` ... ```) и комментарии в них — оставлять как есть, перевода под ними не добавлять.
- Идентификаторы `M-FOO-BAR`, ссылки и определения ссылок внизу файла (`[M-...]: ...`), URL.
- Имена крейтов, типов, функций, атрибутов, термины в `` `обратных кавычках` ``.
- Строки `<!-- Copyright ... -->`, `<version>`, `{{#include ...}}`, `<div ...>`, `<tip></tip>` и прочие теги/директивы.
- Файлы `README.md` категорий содержат `{{#include}}` — их содержимое переводится в самих включаемых файлах `M-*.md`; в README переводить только свой заголовок.

## Терминология

- must → «должно/должен», should → «следует».
- guideline → «руководство», crate → «крейт» (не «ящик»), library → «библиотека», application → «приложение».
- trait, lifetime, borrow, panic, async и т.п. — оставлять латиницей или использовать устоявшиеся «трейт», «время жизни», «паника».
- Стиль: нейтральный технический, без отсебятины. Не добавлять и не убирать смысл.

## Порядок работы

1. Прочитать `TRANSLATED.md` — там список уже переведённых страниц. Не переводить их повторно.
2. Перевести выданные файлы согласно правилам выше.
3. Не трогать файлы вне выданного раздела, `book.toml` и `style/`.
4. Проверить: `mdbook build` проходит без ошибок, код и ссылки не изменились (`git diff` показывает только добавленные строки с `class="ru"`, кроме случаев вложенных списков).
5. Добавить переведённые файлы в `TRANSLATED.md`.
